# Bookmops (`@bookmops/customer`)

The iOS and Android app for customers. Expo SDK 57, expo-router, bundle id
`com.bookmops.app`. Built on the same packages as Bookmops Pro; see
`apps/staff/README.md` for running and the known gotchas, which apply here too.

Its screens (`docs/design/mobile/Cust*.html`) are built after Bookmops Pro.
