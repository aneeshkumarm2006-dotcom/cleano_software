# Documentation

Everything here used to sit loose in the repository root — twenty-four markdown
files, a PDF and two CSVs, in one alphabetical wall where `CHANGES.md` sat next
to `CRM.md` and neither told you which mattered today. The folders below are the
questions people actually arrive with.

Some of these files are read by scripts, not just by people. Those are marked;
moving one means updating the script that reads it.
